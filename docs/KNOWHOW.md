# ブログ・アフィリエイトのノウハウ

記事やページを作る前、何を作るか決めるときに読む。外部の記事から学んだことを、手取りナビに当てはめてまとめる。
（元の記事の文章はそのまま使わず、要点を自分の言葉でまとめる。出典は各章に書く）

---

## 1. 稼げるブログの5ステップ
出典：「やましょ」さん（ブログアフィリエイトで2025年3月に独立、ブログ歴4年半）のリベシティ記事「アフィリエイトブログの正しい5ステップ」を要約。1人の実践者の経験則なので、数字は目安として使う。

### 結論
1. **売る商品を決める**
2. **その商品を売るためのキーワードを選ぶ**
3. **上位を取れるタイトル・目次（見出し）を考える**
4. 本文を書いて公開する
5. 分析して直す（リライト）

いちばん大事なのは❶と❷。ここを間違えると、記事の出来が良くても稼げない。
商品を先に決めると、書くべき記事がわかるので、ムダな記事が減る。

### よくある失敗
「書けそうな記事をひたすら書く → 誰にも読まれない → 読者が来ても売るものがない」。
ただし、書いた経験で文章力や操作は身につくので、ムダではない。

### ❶ 商品の選び方
- 失敗しやすい選び方：
  - 単価が安すぎる
  - 承認率（成果が確定する割合）が低すぎる
  - 成果の条件が厳しすぎる
  - そもそも広告がないジャンルを選んでいる
- 月5万円を目指す最低ラインの目安：
  - 単価3,000円以上
  - 承認率50%以上
  - 自分で使ったことがあり、心からすすめられる

### ❷ キーワードの選び方
- 「商品名 口コミ」「商品名 比較」のような**申し込み直前の言葉は、企業サイトが強くて個人では勝ちにくい**
- 代わりに、**その商品が悩みの解決策になり、競合が弱い言葉**を狙う（例：「夏までに5キロ痩せたい」）
- 絞り込みの基準：
  - 検索数が月10回以上ある
  - 検索1ページ目（10位以内）に個人のサイトがある
- 上位を取れても、売りたい商品とつながらない言葉なら稼げない。「上位になったら商品が売れるか」まで考える

### ❸ タイトル・目次の作り方（見出しの3原則）
1. **読者がいちばん知りたい見出しから順に並べる**
   - 読者は全部読まない。欲しい情報がなさそうならすぐ帰る
   - すぐ帰られる記事は検索順位が下がる
   - 「なぜこの見出しが一番上か」を説明できるようにする
2. **H3（小見出し）には、H2（大見出し）の答えを書く**
   - 目次だけ読めば、中身がだいたいわかるようにする
   - 例：H2「5つのステップ」なら、H3に5つのステップそのものを書く。「注意点」「私の失敗談」のような見出しにしない
3. **余計なH2を書かない**
   - 検索した人がすぐ知りたいこと以外（「○○とは」「○○の歴史」など）は入れない
   - 「その言葉で検索する人は、何をどこまで知っていて、何を判断したいのか」を考えて作る

作る順番：
1. まず検索する人になりきって、自分で考える
2. 思いつかないときだけ、上位の記事を参考程度に見る

上位の記事は、会社のサイトだから上位にいるだけということも多い。
**目次をAIに丸投げしない**（自分で考えたほうが魅力的になる）。

### ❹ 本文・公開
目次ができていれば、方向は大きく外れない。あとで直す前提なので、完璧を目指さず、おおよそできたら公開する。

### ❺ 分析・改善
- Search Console で、狙った言葉で何位か確認する
- 順位がつくまで数週間〜数か月かかる
- 最初は10〜20位に入れば十分。そこからリライトで1位を目指す

## 2. 手取りナビに当てはめると

### ❶ 売る商品（読者の得になるものだけ。CLAUDE.md の方針・もしもの規約が優先）
| 読者の悩み | 解決になる商品（候補） | つながるページ・記事 |
|---|---|---|
| 税金を減らしたい | ふるさと納税サイト | 年収別のふるさと納税の上限、豆知識（12月31日締め切り） |
| 節税しながら老後資金を作りたい | iDeCo・NISA の証券口座 | /guide/ideco.html、/guide/nisa.html、年収別のiDeCo節税額 |
| 子どもの教育費 | こどもNISA（2027年〜）に対応する証券口座 | /guide/kodomo-nisa.html |
| 手取りを増やしたい | 転職サービス | /hikaku.html、昇給の手取り、年収アップの記事 |

- 単価・承認率・成果の条件は、**もしもアフィリエイトの提携画面で確認してから**表に書き足す（推測で書かない）
- 「自分で使って心からすすめられる」の代わりに、手取りナビは「計算で読者の得が数字で示せるもの」を選ぶ
- 転職サービスは成果の条件が厳しいことが多い。単価だけで選ばない

### ❷ キーワード
- 手取りナビの強みは、計算で答えを出す細かい言葉。たとえば：
  - 「年収○万 手取り」
  - 「月給○万 手取り」
  - 「年収○万 ふるさと納税 上限」
  - 「年収○万 iDeCo 節税」
- このうち **「ふるさと納税 上限」「iDeCo 節税」系は❶の商品に直接つながる** → 優先して記事・ページを増やす
- 「NISA おすすめ 証券会社」のような申し込み直前の言葉は、証券会社や大手メディアが強いので狙わない
- 検索数と競合の確認：
  - 検索数：オーナーが無料ツール（Googleキーワードプランナー、ラッコキーワードなど）で調べる
  - 競合：実際に検索して、1ページ目に個人サイトがあるかを見る
  - Search Console に出てきた検索語も候補にする

### ❸ 見出し（いまの記事の直すところ）
自動で作るブログ記事に、答えを書いていない見出しがある。目次だけで中身がわかる見出しに直す：

| いまの見出し | 直す方向（例） |
|---|---|
| 「結論」 | 「結論：年収600万円なら○○県が最も多い（最下位と年○円差）」 |
| 「ポイント」 | そのポイントを見出しにする（例：「増えた分の約3割は税金と保険料」） |
| 「なぜ差が出るの？」 | 「差が出るのは健康保険料率の違い」 |
| 「もっとくわしく」 | 何がわかるかを書く（例：「自分の年収で計算する」） |

- サイトのページも同じ考え方（例：/kabe.html は冒頭で結論を見せる形にすでに変更済み）
- 記事の型はプログラムで作るが、**見出しの構成はオーナーが確認する**（目次をAIに丸投げしない。もしもの規約でも、AIで作った記事は人の確認が必須）

### ❺ 分析・改善の回し方
1. 月1〜2回、オーナーが Search Console の「検索パフォーマンス」（クエリ・ページ・掲載順位）を共有する
2. **10〜20位のページ**を優先してリライト：見出しの順番、答えを先に書く、足りない情報を足す
3. 1位〜10位のページは「次に知りたいこと」から商品につながるページへの導線を確認する
4. 結果を `docs/PLAN.md` の進捗ログに残す
