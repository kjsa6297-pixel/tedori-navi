## 「次に知りたいこと」の並び順の根拠
初期値は「年収○万 手取り」で検索する人が続けて調べることが多いテーマ（月の手取り・家賃・生活・昇給・既婚/独身・ふるさと納税）から推定した仮説。
自サイトのデータがまだないため、GA4 の `next_click` が集まり次第、実際のクリック率で並べ替える。
